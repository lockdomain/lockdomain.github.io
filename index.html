ShipCard

Two screenshots in, a Before / After card out. Show what you shipped, not what you committed.
SafeShot

SubSniff

Drop a bank CSV, see every subscription, its yearly cost and which prices went up.
ThreadKit

Write X threads with exact character counts, auto numbering and reach checks.
DevCard

Your GitHub profile as a card worth sharing. Type a username, download a PNG.

Each tool is a few static files with no build step. Read the code, fork it, use it however you like.
